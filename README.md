# AI Manufacturing Engineer

Industrial AI manufacturing intelligence landing page.

## Static HTML version

Open `index.html` directly in a browser, or serve the repository with any static web server. The static page uses `static/styles.css` and has no runtime or backend dependency. The pilot form prepares an email draft; configure the recipient in `index.html` before launch.

## Next.js version

The same page is also available through the Next.js app:

```bash
npm install
npm run dev
```

Build for production with `npm run build`.

One-page Next.js landing site for the AI Manufacturing Engineer product concept.

## Stack

- Next.js
- TypeScript
- Tailwind CSS v4

## Run locally

```bash
npm install
```
