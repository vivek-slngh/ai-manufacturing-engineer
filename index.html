Optical fiber draw is one of the least forgiving processes in manufacturing — microsecond thermal dynamics, sub-micron tolerances, no room to slow down and inspect. We applied data-driven modeling, deep learning and control methods here first because if the approach holds up under these constraints, it generalizes to slower, more forgiving physical processes: extrusion, chemical reactors, semiconductor fabrication, thermal treatment, and beyond.

Proven on a hard process. Built for physical manufacturing broadly.

Case Study — Security Telemetry Health Monitoring

Sensors (EDR / Firewall / Log Forwarders)
→

→

→

→
Agent Interface

A "sensor" doesn't have to be hardware. In a security operations pipeline, an endpoint agent, firewall, or log-forwarding appliance emits telemetry at expected intervals just like a physical sensor emits readings — and it can go silent the same way. We built statistical baselining and anomaly detection that tracks volume and uptime for thousands of these feeds per client and vendor, catching failures before they become blind spots. Intermittent-demand metrics (ADI, CV²) separate naturally sparse or bursty feeds from genuine failures, and a coverage-ratio check — expected vs. actual reporting periods — catches feeds that go silent or degrade quietly. It runs as a multi-stage Snowflake/Python pipeline across a multi-tenant environment, with an MCP-connected agent that engineers can ask directly about a sensor's health or anomalous behavior.
