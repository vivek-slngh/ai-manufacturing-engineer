Case Study — Optical Fiber Drawing Control

Core Deposition
→
Sintering
→
Rod Draw
→
Fiber Drawing
→
Quality

Fiber drawing is hard to control — the physics are nonlinear and delayed, so a fixed model doesn't hold up. Instead, an LSTM network learned the plant's real dynamics from production data, and system identification modeled the controllers under real noise and disturbances. Together, they formed a closed-loop simulation — a digital twin that replaces slow, trial-and-error tuning on live equipment.

Separately, deep reinforcement learning controlled fiber diameter directly, outperforming standard PI and QDMC control on changing target trajectories.

Two approaches, one idea: learn the dynamics, then simulate and control.

Case Study — Security Telemetry Health Monitoring

A "sensor" doesn't have to be hardware. A security tool — an endpoint agent, firewall, or log forwarder — reports in at expected intervals, and can go silent the same way a physical sensor can. Statistical baselining catches thousands of these feeds going quiet or degrading, before they become blind spots, running as a multi-tenant pipeline with an agent engineers can ask about any sensor's health directly.

Same sensor-health thinking. Physical hardware or digital telemetry.
